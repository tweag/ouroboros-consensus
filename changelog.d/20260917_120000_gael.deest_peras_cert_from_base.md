### Breaking

- The ledger now stores Peras certificates typed in Dijkstra block bodies, so
  `getPerasCertInBlock` returns `Maybe` instead of `Either`.
- `Ouroboros.Consensus.Shelley.Node.Peras` exports
  `shelleyBlockBodyPerasCert` and `setShelleyBlockBodyPerasCert`, which read
  and set the Peras certificate of a Shelley block body (only Dijkstra block
  bodies have one).

### Non-Breaking

- Fix the argument order of `PerasCertTooLargeError` at the Dijkstra forging
  site (size limit first, actual size second, as documented).
