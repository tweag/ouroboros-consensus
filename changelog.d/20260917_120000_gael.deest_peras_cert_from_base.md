### Breaking

- The ledger now stores Peras certificates typed in Dijkstra block bodies, so
  `getPerasCertInBlock` and `extractPerasCertFromShelleyBlockBody` return
  `Maybe` instead of `Either`; `LedgerPerasCertError`,
  `PerasTemporaryCertInBlockError`, `toOpaqueLedgerPerasCert` and
  `fromOpaqueLedgerPerasCert` are removed.

### Non-Breaking

- Fix the argument order of `PerasCertTooLargeError` at the Dijkstra forging
  site (size limit first, actual size second, as documented).
